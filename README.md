![About](https://img.shields.io/badge/-Về%20tôi-2ea44f?style=for-the-badge&logo=minecraft&logoColor=white)

- Mình là một **Minecraft Developer**, chuyên phát triển **plugin, server, mod và tool hỗ trợ** cho hệ sinh thái Minecraft.
- Thành thạo các nền tảng: **Spigot / Paper / Bukkit / Purpur**, **Bungeecord / Velocity**, và bước đầu với **Forge / Fabric**.
- Thích tối ưu hiệu năng server, xây dựng hệ thống kinh tế, minigame, và các cơ chế gameplay custom.
- Đang tìm hiểu thêm về **Kotlin cho Minecraft**, **Docker hoá server**, và **NMS/Reflection**.
- Sẵn sàng hợp tác các dự án network Minecraft, plugin thương mại hoặc mã nguồn mở.
- Cách liên hệ mình ở phần bên dưới.
